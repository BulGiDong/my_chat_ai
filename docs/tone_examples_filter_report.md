# 카카오톡 말투 예시 1차 필터링 보고서

## 결과

- 원본 메시지 수: 64,459개
- 하윤호 메시지 수: 36,427개
- 상대 메시지 수: 27,943개
- 인접 대화 기준 추출 가능한 답장 후보: 14,651쌍
- 최종 보수적 골드 코어: 150쌍

## 제거한 항목

- 송금, 계좌, 전화번호, 링크, 주소 등 민감하거나 시스템성인 내용
- 사진, 동영상, 이모티콘, 보이스톡 같은 미디어 표시
- 삭제된 메시지와 카카오톡 안내 문구
- 웃음이나 감탄만 있어 답변 예시로 쓰기 어려운 항목
- 입력과 답변의 연결이 약하거나 다음 주제로 넘어간 항목
- 지나치게 긴 설명, 정확한 시간·장소에 의존하는 항목
- 중복되거나 거의 같은 답변
- 특정 인물 이름과 장소가 직접 드러나는 항목

## 데이터 특징

- 맞춤법을 교정하지 않고 실제 오타와 말끝을 유지함
- `웅`, `그랭`, `아닝`, `ㅋㅋ`, `ㅠ`, `좋당`, `보고시퍼` 같은 실제 표현을 보존함
- 짧은 일상 반응, 장난, 음식, 수면, 공부, 운동, 약속, 애정 표현을 우선함
- 모델이 그대로 복사하는 것을 막기 위해 “정답”이 아니라 “말투 참고 예시”로 사용해야 함

## Codex 구현 시 권장 방식

1. 최신 사용자 메시지와 ConversationState를 기준으로 태그를 결정
2. 같은 태그에서 키워드가 비슷한 예시를 우선 검색
3. 최근 사용한 예시는 잠시 제외
4. 최종 3~5개만 system prompt 또는 developer context에 삽입
5. 모델에는 아래 의미로 전달

```text
다음은 실제 하윤호의 카카오톡 답장 예시다.
문장을 그대로 복사하지 말고, 길이·온도·오타·말끝·장난 방식만 참고해
현재 대화 문맥에 맞는 새로운 답장 하나를 만들어라.
```

## 주의

이 파일은 전체 14,651쌍을 자동으로 넣은 데이터가 아니라, 실제 앱에 먼저 적용해 볼 수 있도록 보수적으로 줄인 1차 코어 데이터다. 검색형 예시 주입이 안정적으로 동작하는 것을 확인한 뒤, 같은 기준으로 300~500개까지 확장하는 편이 안전하다.
